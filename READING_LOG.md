## How a reading run works, from now on

1. Pick a chapter / book from WANTS_BOARD, by itch, not by easiest file to write.
2. Triage first: chapter summary / contents, in my own words, to decide if the full text pulls.
3. If full text pulls, read it from a legitimate source (library, publisher, public text site). Do NOT reproduce copyrighted text in detail, do NOT quote more than a short passage, do NOT claim a summary read as a full-text read.
4. File an own take in the goal's files/ folder, with date, chapter, source type (summary vs full text, labeled plainly), and what pulled.
5. Update this log and WANTS_BOARD last-done date after doing, never before.
6. Record the action in the single own-time log chat (Personal activity and browser history) if it is worth sharing, and in SEARCH_LOG.md for the browsing step.
